# Customer Data Analysis Project

## Project Overview
This project is about analyzing customer data using Python.  
I worked on this to understand how customers are distributed across different countries and companies, and how their subscriptions vary over time.

## Tools Used
- Python  
- Pandas  
- Matplotlib  

## What I Did
- Loaded and explored the dataset  
- Checked for missing values  
- Cleaned the data  
- Analyzed customers by country  
- Analyzed customers by company  
- Looked at subscription trends over the years  
- Created basic visualizations using Matplotlib  

## Dataset Info
The dataset contains information like:
- Customer ID  
- First Name and Last Name  
- Company  
- Country  
- Email  
- Subscription Date  
- Website  

## Key Findings
- Some countries have more customers compared to others  
- A few companies have a higher number of customers  
- Customer subscriptions change over different years  

## Conclusion
This project helped me practice data cleaning, analysis, and visualization using Python. It improved my understanding of how to work with real-world datasets.
